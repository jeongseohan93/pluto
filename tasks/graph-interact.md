# Graph 탭 ? 노드 드래그 + 패널 최소화

## 요구사항
### 1. 노드 드래그 이동 (세션 내 임시)
- 노드를 마우스 드래그로 자유 이동. 연결된 엣지는 실시간 추종
- 위치는 세션 내에서만 유지 (저장 안 함 ? 새로고침/rebuild 시
  기본 배치 복귀). 영구 저장은 이번 범위 밖
- 드래그 중 텍스트 선택 방지, 클릭(선택)과 드래그 구분 처리
### 2. 좌측 패널 최소화
- 워크스페이스/파일 패널을 접기 버튼으로 최소화 (아이콘 바 수준
  으로 축소 또는 완전 접기 ? plan에서 기존 레이아웃 구조 보고 결정)
- 접힌 상태에서 그래프 캔버스가 그 공간을 차지
### 3. 우측 패널(인스펙터) 최소화
- 동일 ? 접기/펴기 토글, 접힘 시 캔버스 확장
- 노드 선택 시 접혀 있으면 자동으로 펴짐 (선택했는데 정보가 안
  보이는 상황 방지)

## 하지 않는 것
- 위치 영구 저장 / 자동 재배치(force) / 줌·팬 변경 (기존 유지)

## Done Criteria
- 노드 드래그 시 엣지 추종, 클릭 선택과 충돌 없음
- 양쪽 패널 접기/펴기 동작, 접힘 시 캔버스 확장
- 접힌 인스펙터가 노드 선택 시 자동 펴짐
- 기존 pytest 전량 통과
