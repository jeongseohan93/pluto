# Graph 탭 — 줌 LOD + 미니맵 (대형 그래프 가독성)

## 배경
1435 함수 규모에서 전체 뷰가 판독 불가 (실측). 지도에 축척을 넣는다.

## 요구사항
### 1. 줌 기반 LOD 렌더
- 줌 아웃(원경): 파일 박스만 — 파일명 + 함수 수 + 명세 커버리지
  표시. 함수 노드·개별 엣지 숨김, 파일 간 집계 엣지는 유지
- 중간: 파일 박스 + 핵심 함수만 (callers 상위 N 또는 export된 것)
- 줌 인(근경): 전체 함수 (현재 화면) — 기존 동작 유지
- 전환 임계값은 상수로 (실측 후 조정 가능하게)
### 2. 미니맵
- 우하단 소형 전체 조감 + 현재 뷰포트 사각형 표시
- 미니맵 클릭/드래그로 뷰포트 이동, 접기 가능
### 3. 검색 연동 확인
- 검색 선택 시 해당 노드로 줌+센터링 (미동작 시 수정)
