# Graph 탭 — LOD 엣지 + 시각 다듬기

## 요구사항
### 1. LOD 엣지 (평시에도 연결이 보이게, 스파게티 없이)
- 평시(전체 뷰): 파일 간 집계 엣지만 렌더 — 파일A→파일B 호출
  총량을 선 굵기로. 개별 함수 엣지는 렌더 금지
- 노드 선택 시: 해당 함수의 calls/callers 개별 엣지 (기존 동작
  유지·보강), 선택 해제 시 집계 뷰 복귀
### 2. 시각 다듬기
- 엣지는 곡선(베지어), calls/callers 방향·색 구분, 화살표 표시
- 노드 선택 시 무관 노드·엣지 디밍 (포커스 효과)
- 호버 시 해당 노드+직접 이웃 하이라이트
- 색·간격은 기존 다크 테마 팔레트 준수, 과한 애니메이션 금지
### 3. 성능 가드
- 집계 엣지 계산은 DB 조회로 (렌더 시 매번 전체 스캔 금지 —
  파일 쌍별 카운트 쿼리 또는 1회 계산 캐시)

## 하지 않는 것
- 전체 함수 엣지 동시 렌더 / 물리 시뮬레이션 배치 / 신규 그래프
  라이브러리 도입
